# gDeadShallNotBlockArrows

gDeadShallNotBlockArrows is a Union plugin for Gothic 1, Gothic Sequel, Gothic 2 and Gothic NotR.

If you ever got annoyed by monsters blocking your arrows while performing a dying animation, this plugin is for you. Now giant bugs and crawlers, known for their long death animations, no longer will be a nuisance for your archery.

## Requirements

- [Union Primary Universal](https://drive.google.com/file/d/1HujF5KCAKlvqL5Qi8EtiT8GsG5WDpDf2/view)
- [Union 1.0m](https://drive.google.com/file/d/1AkU5qvxIx7zc3kdpGAwlgA-2WiGS7sU5/view) - if you wish to use an older version, you need [zParserExtender](https://worldofplayers.ru/threads/41999/) as well.

## Installation

All you have to do is put **gDeadShallNotBlockArrows.vdf** inside `/Data/Plugins` directory of your Gothic installation. You can download it from the [releases](https://github.com/Kormic1/gDeadShallNotBlockArrows/releases) subpage of this repository.

Enjoy.
